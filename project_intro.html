三磊 / 个人助手

一个面向个人的 Web 助手：把活动安排、费用记账、笔记、知识库与 AI 对话收进同一个站点，由规则引擎 + AI 生成每天可一键执行的建议。

7 个 Django app 5 个三方依赖 524 个自动化测试 PWA 可安装 移动 / 桌面双端适配

01项目定位与概览

站点名「三磊」，基于 Django 5 构建的单用户 / 少用户个人助手。数据全部本地持有（SQLite），AI 能力通过 Qoder Cloud 平台接入，整体形态是「自托管 + 轻量 + 可离线安装（PWA）」。

是什么个人事务中枢

  • 活动 / 行程管理：状态流转、子任务、标签、参与者
  • 费用记账：逐笔消费挂到活动，自动累计与报表
  • Markdown 知识库 + 快速备忘
  • AI 对话：直接用自然语言查活动、记费用、写知识

凭什么AI 驱动的主动性

  • 首页即「今日」简报：子任务、建议、活动一屏读
  • 建议规则引擎 11 条规则自动生成
  • 建议可一键执行（跳转 / 调工具 / 唤起快记浮层）
  • 一句话建活动：AI 解析自然语言回填表单

怎么用PWA + 多端

  • Service Worker + manifest，可安装到主屏离线壳
  • 移动端堆叠 / 桌面端双列，断点唯一（768px）
  • 日志与部署脚本齐备，一台 VPS 即可跑起来
  • Django Admin 兜底管理所有数据

03核心设计亮点

这些约定全部落在代码与回归测试里：改错会被测试拦下，而不是等上线后暴露。

1

安全按用户的数据可见性隔离

所有业务查询必须经由 core.utils 的两个入口，禁止裸用 Model.objects.all()：超级用户可见全量数据，普通用户只见自己的。

# core/utils.py —— 全站唯一口径
qs = visible_qs(Activity, request.user)   # 列表
obj = get_visible(Activity, request.user, id=aid)  # 单对象，无权即 404
2

AI 编排Agent 工具协议与分级降级

各 app 用 @agent_tool 装饰器把业务能力注册进 core.agent_registry；对话编排器按错误类型分级降级，任何失败都转为友好文本，绝不阻断对话。

异常行为
CandidateToolError渲染候选卡片让用户选择
ToolError拼接 ⚠️ 提示返回
Exception固定文案 + logger.error
3

前端HTMX 与原生 fetch 双协议

UI 局部更新走 HTMX + HTML 片段；返回 JSON 的数据端点必须用原生 fetch() 消费，元素上严禁挂 hx-*（HTMX 会把 JSON 当纯文本插入 DOM，还会与 fetch 竞争）。CSRF 统一读 <meta name="csrf-token">，并禁止手动 htmx.process()（内置 MutationObserver 已足够，重复处理会双重绑定）。

4

响应式md: 768px 唯一断点

移动端堆叠、桌面端横排，结构性显隐只用成对类：hidden md:flex / md:hidden。模板里出现第二个结构性断点会被回归测试直接判失败；640–768px 平板竖屏跟随桌面布局是预期行为。

5

建议引擎三态 action 一键执行

每条建议可携带 kind: link / tool / post 的动作：跳转对应页面、调用白名单工具（如一键完成活动），或唤起快记浮层。工具调用走 SUGGESTION_TOOLS 白名单 + HMAC token 两步确认，执行后自动标记已读；旧缓存建议缺少字段时优雅降级为纯链接。

# core/suggestions.py —— 规则顺序执行
_RULES = [_rule_tomorrow_starts, _rule_no_start_date,
          _rule_subtask_progress, ...]
6

容错AI 链路全量降级

所有 AI 调用都有规则兜底：一句话解析 AI 失败 → 本地规则解析；记忆聚合失败 → 静默跳过。非核心操作失败只记日志（logger.warning），用户侧无感。

回归锁文化：布局与约定都有测试守着（点击展开）

全量 524 个测试中，除功能用例外还有一类「回归锁」：断言桌面两列布局的 DOM 顺序、右列 sticky 是否还在、模板是否混入 sm: 结构断点、品牌名是否写死、{# #} 注释是否跨行等。这类锁防的是「不报错、只在真机上退化」的问题。

python manage.py test                    # 全量 524 个用例
python manage.py test core activities    # 指定模块

04技术栈与部署

依赖刻意保持最少：requirements.txt 只有 5 个直接依赖，其余能力全部用 Django 原生与标准库实现。

技术栈框架与存储

选型说明
Django 5.2django>=5.0,<6.0，函数视图为主，混用少量 CBV
SQLite单文件数据库，个人规模够用且备份简单
django-htmx + HTMX局部渲染与无刷新交互（hx-post / hx-target / hx-swap）
Tailwind CSS原子类 + CSS 变量（--text / --bg / --border）黑白灰阶设计系统
Redis生产环境缓存后端（建议结果、会话等），开发用 LocMemCache
httpx[http2]调用 Qoder Cloud AI 平台（对话、解析、周报）
django-taggit / django-environ活动标签 / .env 配置管理

部署形态gunicorn + nginx + cron

组件说明
gunicorn3 workers + unix socket，--timeout 180（AI 请求最长 90s，网关必须外大内小）
nginxHTTPS（Let's Encrypt 自动续期）、staticfiles 别名、client_max_body_size 12m 配套 10MB 附件上传
PWA/sw.js 由 Django 视图从站点根下发（控制全站 scope），manifest 定义「三磊」安装名与 maskable 图标
# crontab —— 幂等定时任务

0  3  * * 0  consolidate_memories    # 每周聚合记忆画像
